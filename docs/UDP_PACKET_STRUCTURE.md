# Структура UDP-пакетов Simple Voice Chat

Основано на анализе исходного кода сторонних реализаций (PumpkinVoice).

## Общая структура фрейма

Каждый UDP-datagram, отправляемый или получаемый клиентом, имеет следующую структуру:
1. `magic_byte` (обычно 1 байт, в некоторых реализациях отсутствует на уровне приложения, но присутствует в сетевом слое)
2. `player_uuid` (16 байт) - UUID отправителя
3. `encrypted_payload` (оставшиеся байты) - зашифрованная полезная нагрузка

Шифрование `encrypted_payload` выполняется с использованием AES-GCM, где `Secret` - это 16-байтовый сессионный секрет, полученный через bootstrap.

## Расшифрованная полезная нагрузка (Payload)

После расшифровки полезная нагрузка всегда начинается с 1-байтового идентификатора типа пакета (`type_id`), за которым следуют данные, специфичные для этого типа.

### Идентификаторы типов пакетов (`type_id`)

- `0x1` - Mic (Аудио с микрофона)
- `0x2` - PlayerSound (Звук от конкретного игрока)
- `0x3` - GroupSound (Звук от группы)
- `0x4` - LocationSound (Звук из определенной локации)
- `0x5` - Authenticate (Запрос аутентификации от клиента)
- `0x6` - AuthenticateAck (Подтверждение аутентификации от сервера)
- `0x7` - Ping (Пинг для проверки задержки)
- `0x8` - KeepAlive (Поддержание соединения)
- `0x9` - ConnectionCheck (Проверка соединения от клиента)
- `0xA` - ConnectionCheckAck (Подтверждение проверки соединения от сервера)

### Структуры пакетов

#### AuthenticatePacket (`0x5`)
Отправляется клиентом для инициализации UDP-сессии.
- `player_uuid` (16 байт) - UUID игрока
- `secret` (16 байт) - Сессионный секрет

#### AuthenticateAckPacket (`0x6`)
Отправляется сервером в ответ на успешную аутентификацию.
- Нет дополнительных данных.

#### ConnectionCheckPacket (`0x9`)
Отправляется клиентом после `AuthenticateAck` для завершения handshake.
- Нет дополнительных данных.

#### ConnectionCheckAckPacket (`0xA`)
Отправляется сервером в ответ на `ConnectionCheck`.
- Нет дополнительных данных.

#### PingPacket (`0x7`)
- `id` (16 байт) - UUID (обычно случайный для каждого пинга)
- `timestamp` (8 байт, i64) - Временная метка отправки

#### KeepAlivePacket (`0x8`)
- Нет дополнительных данных.

#### MicPacket (`0x1`)
Отправляется клиентом, содержит Opus-закодированное аудио.
- `data` (byte array: длина + байты) - Opus аудиоданные
- `sequence_number` (8 байт, i64) - Порядковый номер пакета
- `whispering` (1 байт, bool) - Флаг шепота (0 или 1)

*Примечание: `byte_array` обычно сериализуется как длина (часто varint или 4 байта), за которой следуют сами байты.*

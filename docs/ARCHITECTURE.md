# Архитектура проекта

## Принцип безопасной изоляции

Клиент разделён на независимые проекты. UI не знает формата UDP-пакетов, аудиокодирование не знает UI, а доступ к сессионному секрету ограничен `SessionBootstrap`. Секрет нельзя сериализовать в настройки или логировать.

| Проект | Ответственность |
|---|---|
| `StandaloneVoiceChat.Protocol` | Версии протокола, bootstrap-контракты, машина состояний, будущие изолированные adapter-ы. |
| `StandaloneVoiceChat.Network` | DNS и безопасная диагностика UDP без ложной интерпретации `UDP Connect` как серверного успеха. |
| `StandaloneVoiceChat.Audio` | Абстракции захвата, воспроизведения и Opus; реализации появятся только с проверенным SVC adapter-ом. |
| `StandaloneVoiceChat.Client` | Оркестрация попытки подключения, состояние и fail-closed обработка отсутствующего bootstrap. |
| `StandaloneVoiceChat.ProtocolTest` | Консольная проверка входных данных и сетевых предпосылок без отправки фиктивных пакетов. |
| `StandaloneVoiceChat.UI` | Avalonia UI, MVVM, настройки состояния и отображение диагностических результатов. |
| `StandaloneVoiceChat.Tests` | Unit tests для машины состояний, валидации endpoint и обращения с секретом. |
| `paper-plugin` | Минимальный Paper plugin, зарегистрированный через официальное SVC API; не реализует API-сервер и не создаёт обходных подключений. |

## Будущий поддерживаемый путь

После появления официального SVC extension point или документированного bootstrap-провайдера потребуется создать реализацию `ISvcProtocolAdapter` и интеграционные тесты против конкретной версии Paper/SVC. До этого интерфейс показывает реальное ограничение вместо фиктивного «Connected».
